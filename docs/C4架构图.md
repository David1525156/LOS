# 在线图书借阅系统 C4 架构图（Sprint1）

## 1. 系统上下文图（System Context Diagram）

> 参与者：普通读者、管理员、在线图书借阅系统。Sprint1 无外部第三方系统。

```mermaid
flowchart LR
    Reader["普通读者<br/>(Person)"] -->|"浏览图书列表、查看图书详情"| OLS["在线图书借阅系统<br/>(系统边界, Sprint1)"]
    Admin["管理员<br/>(Person)"] -->|"登录、新增/修改/删除图书"| OLS
```

- **普通读者**：免登录浏览图书，使用 US-01 / US-02。
- **管理员**：登录后管理图书信息，使用 US-03（及修改、删除）。
- **外部依赖**：Sprint1 不依赖任何第三方系统，仅内部数据库。

---

## 2. 容器图（Container Diagram）

> 三个容器：Vue3 前端（浏览器）、Spring Boot 后端 API、MySQL 数据库。

```mermaid
flowchart LR
    subgraph Browser["浏览器"]
        FE["Vue3 前端<br/>(Vite + Element Plus SPA)<br/>容器：Web 应用"]
    end
    BE["Spring Boot 后端<br/>(REST API :8080)<br/>容器：Web 应用"]
    DB[("MySQL 8.0<br/>library 数据库<br/>容器：数据库")]

    FE -->|"HTTP / JSON<br/>/api/**"| BE
    BE -->|"JDBC + MyBatis-Plus"| DB
```

- **Vue3 前端**：用户界面容器，Vite dev server 通过 `/api` 代理请求后端。
- **Spring Boot 后端**：业务与 API 容器，统一 `{code,message,data}` 响应。
- **MySQL 数据库**：持久化容器，`book`、`admin` 两张表。

---

## 3. 组件图（Component Diagram，后端内部）

> 核心链路：BookController → BookService → BookRepository；图中同时标注了登录认证与通用组件。

```mermaid
flowchart TB
    subgraph Controller["Controller 组件（api/**）"]
        BookC["BookController<br/>GET /api/books<br/>列表分页 / 详情"]
        BookAdminC["BookAdminController<br/>POST /api/books<br/>新增图书"]
        BookManageC["BookManageController<br/>PUT / DELETE /api/books/{id}<br/>修改 / 删除图书"]
        AuthC["AuthController<br/>POST /api/auth/login"]
    end

    subgraph Service["Service 组件"]
        BookS["BookService<br/>分页查询 / 详情校验"]
        CreateS["BookCreateService<br/>新增图书"]
        ManageS["BookManageService<br/>修改 / 删除"]
        AuthS["AuthService<br/>账号校验 / 签发 token"]
    end

    subgraph Repository["Repository 组件（Mapper）"]
        BookR[("BookRepository<br/>BookMapper &lt; BaseMapper&lt;Book&gt;")]
        AdminR[("AdminRepository<br/>AdminMapper &lt; BaseMapper&lt;Admin&gt;")]
    end

    subgraph Support["通用组件"]
        Result["Result<br/>统一响应"]
        ExHandler["GlobalExceptionHandler<br/>全局异常处理"]
        Interceptor["AuthInterceptor + TokenStore<br/>Bearer Token 鉴权"]
    end

    BookC --> BookS
    BookAdminC --> CreateS
    BookManageC --> ManageS
    AuthC --> AuthS

    BookS --> BookR
    CreateS --> BookR
    ManageS --> BookR
    AuthS --> AdminR

    Interceptor -.-> Controller
    Controller -.-> Result
    Result -.-> ExHandler
```

- **Controller 层**：承接 HTTP 请求，参数校验（`@Validated`）。
- **Service 层**：业务逻辑（分页、校验、新增/改/删、登录）。
- **Repository 层**：基于 MyBatis-Plus `BaseMapper` 的数据访问组件。
- **通用组件**：`AuthInterceptor` 拦截 `/api/**` 写操作校验 Bearer Token；`GlobalExceptionHandler` 统一输出友好错误。
