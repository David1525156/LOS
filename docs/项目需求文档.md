## 1. 项目概述

### 1.1 项目背景

传统图书馆的图书信息查询、借阅登记均依赖人工线下操作，效率低、易出错、读者体验差。本系统旨在提供一个**线上图书借阅平台**，实现图书信息的集中展示、查询与管理，为读者提供便捷的线上浏览体验，为管理员提供高效的图书管理手段。

### 1.2 项目目标

- 面向读者：无需登录即可浏览图书列表、查看图书详情，了解可借阅库存；
- 面向管理员：登录后可对图书进行管理，如新增图书；
- 系统稳定可靠，提供友好的错误提示，保证数据一致性。

### 1.3 项目范围

**Sprint 1 实现范围（本期交付）**：

1. 图书列表浏览（分页展示）
2. 图书详情查看
3. 管理员登录后新增图书

**Sprint 1 不做（留待后续迭代）**：

- 用户注册
- 借书、还书功能
- 图书编辑、删除、检索
- 库存自动扣减与归还恢复

## 4. 功能需求（用户故事）

### 4.1 US-01 图书列表浏览

> **用户故事**：作为用户，我希望浏览图书列表。

**功能描述**：系统首页展示图书列表，包含书名、作者、库存信息；列表分页展示，每页 10 条。

**验收标准**：

1. 页面展示全部图书信息：书名、作者、库存；
2. 图书列表做分页，每页显示 10 条数据；
3. 数据加载失败时展示友好的错误提示（不出现白屏）。

**实现说明**：

- 接口：`GET /api/books?page=1&size=10`，按创建时间倒序返回，新书在前；
- 响应包含分页元数据：`records / total / current / size`；
- 前端表格 + 分页器，加载失败显示错误提示与重试入口。

### 4.2 US-02 图书详情查看

> **用户故事**：作为用户，我可以查看图书详情。

**功能描述**：点击图书条目跳转详情页，展示图书完整信息。

**验收标准**：

1. 点击图书条目，跳转到图书详情页面；
2. 详情页面展示：书名、作者、图书简介、可借阅库存数量。

**实现说明**：

- 接口：`GET /api/books/{id}`；
- 图书不存在时返回友好提示「图书不存在」（code 400）；
- 前端路由 `/books/:id`，展示书名/作者/简介/可借库存。

### 4.3 US-03 管理员新增图书

> **用户故事**：作为管理员，我可以新增图书。

**功能描述**：管理员登录成功后打开新增图书表单，填写书名、作者、简介并提交，新增成功后在图书列表可见。

**验收标准**：

1. 管理员登录成功之后，可以打开新增图书表单；
2. 填写书名、作者、简介，提交表单能够成功新增图书；
3. 新增完成后这本新书会出现在图书列表；
4. 输入非法内容要弹出错误提示。

**实现说明**：

- 接口：`POST /api/books`，需携带管理员 token（`Authorization: Bearer <token>`）；
- 校验规则：书名、作者必填（书名 ≤ 100 字符，作者 ≤ 50 字符），简介 ≤ 1000 字符，库存 ≥ 0（默认 1）；
- 非法输入返回 code 400 与明确错误信息；
- 无有效 token 返回 401「未登录或登录已过期」；
- 前端新增成功后跳转列表页，新书出现在第一页首条。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 易用性 | 界面简洁清晰，所有操作有结果反馈（成功/失败提示） |
| 错误处理 | 后端统一返回 `{code, message, data}` 结构；前端统一弹出友好错误提示，不暴露堆栈 |
| 性能 | 列表分页查询，避免全量加载；默认每页 10 条，上限 100 条 |
| 安全 | 新增等写操作经登录鉴权拦截；密码暂存明文（演示期），后续迭代升级为 BCrypt |
| 编码 | 全链路 UTF-8，数据库 utf8mb4，支持中文内容 |
| 兼容性 | 后端兼容 Java 8 环境；前端支持现代浏览器 |

## 6. 接口设计

统一响应结构：

```json
{
  "code": 200,
  "message": "ok",
  "data": {}
}
```

| code | 含义 |
| --- | --- |
| 200 | 成功 |
| 400 | 业务/参数校验错误 |
| 401 | 未认证或登录过期 |
| 500 | 服务器内部错误 |

### 6.1 接口清单（Sprint 1）

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/books` | 无 | 分页查询图书列表，参数 `page`（默认 1）、`size`（默认 10） |
| GET | `/api/books/{id}` | 无 | 查询图书详情 |
| POST | `/api/books` | Bearer Token | 新增图书 |
| POST | `/api/auth/login` | 无 | 管理员登录，返回 token |

### 6.2 分页响应示例

```json
{
  "code": 200,
  "message": "ok",
  "data": {
    "records": [{ "id": 1, "title": "三体", "author": "刘慈欣", "stock": 8 }],
    "total": 25,
    "current": 1,
    "size": 10
  }
}
```

## 7. 数据模型

### 7.1 图书表 book

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | 主键，自增 | 图书 ID |
| title | VARCHAR(100) | 非空 | 书名 |
| author | VARCHAR(50) | 非空 | 作者 |
| description | VARCHAR(1000) | 可空 | 图书简介 |
| stock | INT | 非空，默认 0 | 可借阅库存 |
| create_time | DATETIME | 默认当前时间 | 创建时间 |

### 7.2 管理员表 admin

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | 主键，自增 | 管理员 ID |
| username | VARCHAR(50) | 非空，唯一 | 用户名 |
| password | VARCHAR(100) | 非空 | 密码（演示期明文，后续改 BCrypt） |
